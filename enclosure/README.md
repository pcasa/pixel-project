# Enclosure Design Notes

## Target Design
- Puck/cylinder shape, ~70–80mm diameter, ~50mm tall
- Round display flush with top face
- Camera hole forward-facing, same axis as display
- Speaker grille on front or side
- USB-C exit at rear bottom
- Ventilation slots (ESP32-S3 runs warm)
- Snap-fit or M2 screw lid — no glue

## Print Settings (Bambu X1)
- Material: PETG (heat tolerance near USB-C)
- Layer height: 0.2mm
- Infill: 15% gyroid
- Supports: required for cutouts
